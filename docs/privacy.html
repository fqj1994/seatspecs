How SeatSpecs handles information

Privacy policy

Last updated: November 4, 2026

SeatSpecs displays seat types, legroom and Wi-Fi information in Google Flights results. It has no developer-operated backend, advertising system or analytics service.

The short version

  • No injected ads or background ad pop-ups.
  • No tracking, telemetry or persistent search history.
  • Flight information is processed locally, not sent to the developer.
  • No extra flight-data requests or third-party seat-information services.

1. What this policy covers

This policy covers the SeatSpecs Chrome extension and this project website. The extension’s purpose is to make onboard comfort easier to compare in collapsed Google Flights search results. It currently supports Google Flights only.

2. Information processed by the extension

SeatSpecs reads relevant information already loaded by Google Flights. This includes flight-search context such as airports, travel dates and cabin; flight numbers and result identifiers used to match rows; seat types and pitch measurements; Wi-Fi availability and pricing flags; and the page language.

It observes existing page data and copies of Google Flights’ native shopping responses. It does not automatically expand flights, send extra flight-data requests, or obtain information from an external seat-data provider. Authentication and session fields are not forwarded to the extension’s display layer or saved.

This processing happens locally in the browser to match each result with the correct information. SeatSpecs does not transmit search information or page content to the developer or any other recipient.

3. Storage and retention

The extension uses a bounded, in-memory cache while the Flights page is open. It does not write a search history to disk, browser storage or cloud storage. It does not use cookies or request Chrome’s storage or browsing-history permissions.

There is no SeatSpecs account and no server-side profile. Closing a Flights page ends that page’s live extension processing; there is no developer-held search history to request or delete.

4. No advertising, tracking or sale of data

SeatSpecs does not inject ads, open background advertising pop-ups, insert sponsored placements, or perform affiliate redirects. It has no analytics SDKs, tracking pixels or telemetry.

The developer does not receive, sell, rent or share your flight-search information. SeatSpecs is not an ad blocker and does not change advertising or data collection performed independently by Google.

5. Why Google site access is needed

The extension’s content scripts are limited to Google Travel/Flights URL patterns across Google’s regional domains. Access allows SeatSpecs to observe the information Flights already loads, match results and add seat and Wi-Fi details to the page.

The Travel path coverage also supports in-page navigation into Flights. This access is used for the Flights feature, not unrelated browsing, advertising or tracking. SeatSpecs does not request tabs, debugger, cookies, browsing-history, webRequest or storage permissions.

6. This website and GitHub Pages hosting

This website has no JavaScript, analytics, tracking pixels, advertising, cookies set by the site, or embedded third-party resources. Its images, icon and stylesheet are served with the site.

When hosted on GitHub Pages, GitHub processes requests to deliver the website. GitHub states that visitors’ IP addresses are logged and stored for security purposes, whether or not they are signed in. This hosting activity is separate from the extension and is governed by GitHub’s Privacy Statement. See also GitHub Pages’ data-collection disclosure.

7. Google and other services

Using Google Flights or the Chrome Web Store is subject to those services’ own policies. Their normal requests, account handling, data collection and extension-distribution mechanisms are not operated by SeatSpecs. This policy describes what SeatSpecs itself does.

Visiting an external link or voluntarily sending a support request is a separate action. Please avoid including booking references, payment details or other sensitive information in public support requests.

8. Changes and contact

Updates to this policy will be published on this page with a revised date. For privacy questions, use the developer contact or support details provided on the SeatSpecs Chrome Web Store listing.
